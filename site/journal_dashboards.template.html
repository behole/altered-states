Each temporal-lab character logs a journal per cycle. These dashboards chart their phenomenology across cycles: intensity and novelty as numeric series, with the cycle's emotional valence, ego coherence and integration state in the hover readout. Every point is the journal's own value for that cycle.

Hover or tap a data point to read that cycle's values.
