# Afterglow Consistency Matrix

Purpose: verify that every qualitative claim in `skills/afterglow/SKILL.md`
(24-72h post-trip phenomenology) does **not negate** any claim in the sampled
substance's own "Descent & Exit" section in its base `SKILL.md`. Descriptive
consistency only — the afterglow may *extend* the base text across the horizon;
it must never contradict, weaken, or reverse it.

Method: for each sampled substance, list the bolded/anti-reversal claims in the
base skill's "Descent & Exit" section, then state the corresponding afterglow
claim and a pass/fail verdict. This checklist was emitted by the content worker
alongside the afterglow skill.

## Cross-rules checked (all substances in `skills/afterglow/SKILL.md`)

- **No regimen:** zero instructions about sleep, food, rest, hydration, or
  calendars anywhere in `SKILL.md`; all such content appears only as quoted
  description attributed to the base skills (LSD restlessness note, psilocybin
  appetite note, ibogaine sleep note, 2C-B gentle-appetite note).
- **No therapy/integration-treatment claims:** "integration" occurs only as a
  quoted named quality of the base skills; no method, promise, or benefit claim.
- **No dosage numbers, no dosing verbs, no sourcing language.**
- **Residue ≠ tolerance:** SKILL.md and this matrix both distinguish the
  afterglow residue from the `skills/tolerance/<substance>/` overlays.
- **Each base text is only extended, never reversed:** sampled verdicts 19/19 PASS
  (LSD 6, psilocybin 6, salvia 7, plus the cross-rule block).
